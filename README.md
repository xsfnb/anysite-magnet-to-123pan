# AnySite Magnet to 123pan（油猴脚本）

在任意网页上自动识别磁力链接，旁边注入「💾 转存123盘」按钮，一键离线下载到 123 云盘；下载完成后自动把单集文件从任务文件夹里取出来，并按番剧名归类到同一个文件夹。

> 基于 [AnySite Magnet to 123pan](https://greasyfork.org/zh-CN/scripts/573781-anysite-magnet-to-123pan)（作者 Nagisa，MIT）修改。
> 本仓库是个人修改版，与 123 云盘官方无关。

## 功能

- **自动识别磁力**：`<a href="magnet:...">` 与 `[data-clipboard-text^="magnet:"]`（各类种子站的复制按钮）
- **一键转存**：点「💾 转存123盘」→ 解析 → 提交离线下载；重复提交同一磁力会二次确认
- **动态页面**：MutationObserver 监听新增节点与 `href` / `data-clipboard-text` 变化，SPA 翻页后自动补按钮
- **下载完成后自动整理**（可切换）：
  - `📚 按番剧归类`（默认）：单集文件移进「番剧名」文件夹，没有就自动建，已有就复用
  - `🧹 仅去掉文件夹`：只把文件移出单集外层文件夹，平铺在当前目录
  - `⛔ 不处理`：保持 123 默认结构
- **番剧名识别**：去掉 `[组名]`、`[1080P]`、`[WEB-DL]` 等标签，截断到第一处集数标记，兼容 `SxxExx` / `EP07` / `第7话` / `[07]` / 独立 `07`；`S02` 及以上会带上季号
- **任务队列**：提交后 45 秒轮询一次离线任务，完成后自动整理；页面隐藏时暂停，队列最长保留 48 小时
- **手动整理**：123 云盘目录页 → 菜单「📚 同剧归类（当前 123 目录）」，单集文件夹和已散落的剧集文件都会归到番剧文件夹
- **Token 同步**：在 123 云盘页面点右下角悬浮球即可把登录状态同步给脚本

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）或 ScriptCat
2. 打开管理面板 → 新建脚本 → 清空模板 → 粘贴 `anysite-magnet-to-123pan.user.js` 全文 → `Ctrl+S`
3. 打开并登录 <https://yun.123pan.cn/>，点右下角蓝色悬浮球同步 Token

## 使用

1. 在任意支持磁力的站点（蜜柑、动漫花园、nyaa、JavDB 等）找到磁力链接，旁边会出现「💾 转存123盘」
2. 点它 → 确认解析结果 → 自动提交离线下载
3. 下载完成后（脚本轮询）自动整理：单集进番剧文件夹，多集任务保持原样
4. 处理方式在油猴菜单第一项切换

### 菜单

| 菜单 | 作用 |
|---|---|
| 完成后处理方式：📚 按番剧归类（点击切换） | 在 按番剧归类 / 仅去掉文件夹 / 不处理 之间循环 |
| 📚 同剧归类（当前 123 目录） | 手动整理当前目录（含散落文件） |
| ⏱ 立即检查待整理任务（N 个） | 立即跑一次队列 |
| 🗑 清空待整理队列 | 清空 |
| 🐞 调试日志：开/关 | 控制台输出 `[123pan]` 日志 |
| 🔑 打开 123 云盘（自动同步登录状态） | 打开云盘页并同步 Token |

## 安全与隐私（请务必阅读）

- 脚本会从 123 云盘页面的 `localStorage` 中读取登录 Token，保存在油猴本地存储（`123_token`），不会上传到除下列域名以外的地方
- **请求发往 `api.123278.com`**（第三方域名，非 123 官方），并携带 `Authorization: Bearer <你的 Token>`、伪造的 `Origin` / `Referer`。也就是说该服务的运营方可以看到你的 Token 和操作内容
- 如果不接受这一点，请不要使用本脚本，或把脚本里的 `API` 常量改成你信任的地址
- 脚本不含统计、埋点、远程配置

## 已知限制

- 依赖 123 云盘网页端接口，官方调整后可能失效（脚本内置多路径回退，但仍可能全挂）
- 自动整理依赖任务队列轮询，下载完成后最多约 45 秒才开始整理
- 手动整理只扫描当前目录的前 80 个文件夹
- 同时下载多个单集时，按时间兜底找目录会校验大小，避免搬错文件；极端情况下会放弃整理并保留原文件夹
- 番剧名靠文件名推断，命名过于混乱时会识别失败（此时不做整理，文件留在原处）
